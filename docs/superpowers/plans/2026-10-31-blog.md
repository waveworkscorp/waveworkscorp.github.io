# 웨이브웍스 블로그 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** md 파일을 넣으면 목록·글·검색·관련 글이 따라오는 ko/en 블로그를 회사 사이트에 붙이고, 주제만 주면 글을 써 주는 `blog-auto-write` 스킬을 만든다.

**Architecture:** Astro content collection(`blog`, glob loader)이 `src/content/blog/{ko,en}/*.md`를 읽는다. 순수 함수(읽는 시간, 관련 글, 짝 검사, 검색 색인)는 의존성 없는 `src/lib/blog-core.ts`에 두고 `node --test`로 검사한다. 화면은 사이트 기존 패턴(Base.astro + View 컴포넌트 + 언어별 얇은 page)을 따른다.

**Tech Stack:** Astro 7.3.8, TypeScript(strict), Node 24 내장 테스트 러너(타입 제거 실행), 바닐라 스크립트.

**Spec:** `docs/superpowers/specs/2026-10-31-blog-design.md`

## Global Constraints

- 카테고리: `making | news | culture`. 이름 ko 제작기·소식·문화, en Making·News·Culture. 색 `--wave`·`--tang`·`--coral`.
- excerpt 140자 이하, tags 1~5개, date `YYYY-MM-DD`, 날짜 표시는 `timeZone: 'Asia/Seoul'`.
- 읽는 시간: 한국어 600자/분(공백 제외 글자), 영어 200단어/분, 최소 1분.
- 주소: `/blog/<파일명>/`, `/en/blog/<파일명>/`. `trailingSlash: 'always'`.
- 영어판만 있는 글, 작품 slug `blog`는 빌드 실패. `works`에 없는 작품 slug는 `console.warn` 후 링크만 뺀다.
- 새 의존성 추가 금지. React·Tailwind 금지. 파일당 300줄 이하. 주석은 "왜"만.
- 두 언어 UI 문구는 함께 추가한다(`STRINGS`와 `src/data/blog.ts`).
- push 금지(사용자 승인 전). `git add`는 경로로, `.omc/` 금지.

4. 표지가 없는 글도 카드·글 머리·og가 깨지지 않아야 한다 → Task 3에서 대체 상자.

### Task 1: 순수 함수 `blog-core.ts`

**Files:**
- Create: `src/lib/blog-core.ts`
- Test: `src/lib/blog-core.test.ts`
- Modify: `package.json` (scripts `"test": "node --test src/**/*.test.ts"`)

**Interfaces:**
- Produces:
  - `readMinutes(body: string, lang: 'ko' | 'en'): number`
  - `interface PostMeta { id: string; lang: 'ko'|'en'; title: string; date: string; category: string; tags: readonly string[]; excerpt: string; featured: boolean }`
  - `relatedPosts(target: PostMeta, all: readonly PostMeta[], limit = 3): PostMeta[]` 같은 언어, 자기 제외, 같은 카테고리 우선, 겹치는 태그 수 내림차순, 날짜 내림차순, id 오름차순
  - `sortPosts(list): PostMeta[]` 날짜 내림차순, 같으면 id 내림차순
  - `findOrphans(ko: readonly string[], en: readonly string[]): string[]` en에만 있는 파일명
  - `searchPosts(query: string, index: readonly SearchEntry[]): SearchEntry[]` (`SearchEntry = { url; title; excerpt; tags; category }`), 공백 기준 낱말 모두 포함(대소문자 무시), 빈 질의는 전체
  - `formatDate(date: string, lang): string` ko `2026. 11. 1.` 형식은 `Intl.DateTimeFormat(lang==='ko'?'ko-KR':'en-US', { timeZone: 'Asia/Seoul', dateStyle: 'medium' })`, 입력은 `${date}T00:00:00+09:00`

- [ ] Step 1: 테스트 작성 — `readMinutes('가'.repeat(1200),'ko') === 2`, `readMinutes('',…) === 1`, `readMinutes('word '.repeat(450),'en') === 3`; `relatedPosts`가 같은 카테고리·태그 2개 겹침 글을 1개 겹침보다 앞에 두고 자신과 다른 언어 글을 빼는지; 같은 입력 두 번 호출 결과가 같은지; `findOrphans(['a','b'],['b','c'])` → `['c']`; `searchPosts('  ', idx).length === idx.length`, `searchPosts('UNITY 출시', idx)`가 태그 `Unity`와 제목 `출시`를 가진 글만; `formatDate('2026-11-01','en')`가 `Nov 1, 2026`.
- [ ] Step 2: `npm test` 실행 → 모듈 없음으로 FAIL.
- [ ] Step 3: 구현.
- [ ] Step 4: `npm test` → 전부 PASS.
